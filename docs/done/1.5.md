- Idempotente (se vuelve a ejecutar sin duplicar) y sin efecto en producción → `seed_demo_catalogue_is_idempotent`, `..._never_in_staging_or_production`.
- No salen en la API pública → `seeded_demo_data_absent_from_public_api`. No pasan a publicados ni por SQL ni se les quita el marcador → `seeded_demo_data_cannot_be_published_by_sql` (y `demo-and-access.test.ts` de 1.1 para la API).
