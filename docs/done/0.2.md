## Qué se hizo

Rutas de `.claude/rules/*` ajustadas, sin `paths`.
## Cómo se comprobó
- Lint, tipos y pruebas en local y CI → `pnpm check:all`; CI `checks` en verde (run 43050561814 en `ddde33e`; 38 pruebas).
- `docker compose up` deja db, mail, api y web sanos → job CI `compose-smoke`. Datos demo: `seed_runs` con `base` (`apps/api/test/db-roles.test.ts`); el seed completo llega con 0.3, 0.5 y 1.5.
- Convenciones del esquema, con fixtures que deben fallar → `apps/api/test/conventions/schema-conventions.test.ts`.
- API no arranca sin `APP_ENV` → `src/platform/config/config.test.ts` y arranque real (sale con 1). `mt_app` sin CREATE ni TRUNCATE ni tablas propias, `mt_app_has_no_create_privilege` → `test/db-roles.test.ts`.
- CI falla con pruebas saltadas → `scripts/check-no-skipped.mjs` y regla de lint; cancela ejecuciones antiguas (`concurrency`); ejecuta `check-dependency-table.mjs` dentro de `pnpm lint`; `prisma migrate diff` comprueba migraciones contra el esquema.
