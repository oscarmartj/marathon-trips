## Cómo se comprobó
- Bandeja, búsqueda, resumen, ficha con historial, alta y edición → `apps/api/test/modules/crm/customers.test.ts`, `test/modules/bookings/state.test.ts`.
- Presupuesto con precio del motor, inmutable, caducidad (nunca tras el día de salida), enviar/retirar/expirar, aceptar una vez o en carrera → `test/modules/crm/quotes.test.ts`.
- Correos por estado, sin duplicados ni a cuentas anonimizadas → `test/modules/crm/emails.test.ts`.
- Notas/etiquetas (0.5) → `customers.test.ts`. Rutas ajenas 404 → `test/modules/access`. Web → `quote-pages.test.tsx`, `copy.test.ts`, `routes.test.ts`.

Notas (también las borradas) exportadas y redactadas, `Quote` exportable → `customers.test.ts`. Correo de caducidad, `deletedAt` y reintentos acotados → `emails.test.ts`.
