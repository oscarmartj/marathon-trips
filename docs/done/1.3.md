# 1.3 Web: inicio, buscador con filtros en la URL y página de carrera
- **Estado:** hecha con pendientes
- **PR:** pendiente
- **Modelo:** Sonnet
- **Revisor:** no aplica (riesgo bajo)

## Qué se hizo
Inicio con búsqueda y carreras destacadas, `/races` (formulario GET con filtros combinados en la URL, paginación) y `/races/[slug]` (guía básica, ediciones y paquetes). Leen `/catalogue/*` con `lib/catalogue.ts` (revalidación de 60 s, `generateStaticParams` tolerante a API caída). Sin precios, sin JavaScript de cliente propio.
## Cómo se comprobó
- Filtros combinados y que sobreviven a recargar → `src/lib/catalogue.test.ts` (URL a filtros y vuelta) y `race finder` en `src/app/catalogue-pages.test.tsx` (la API recibe todos; el formulario los conserva; GET sin JS).
- Fecha sin confirmar visible → pruebas `shows an unconfirmed date visibly` (tarjeta y página).
- Sin «entrada garantizada», socio ni acreditación si la API no lo marca → `shows no guaranteed-entry, partner or accreditation claim unless the API says so`; también `pages.test.tsx`.
- Paquete `draft` fuera de la web → lo garantiza la API (1.1, `draft_package_absent_from_public_api`); la web solo pinta lo que recibe.
- Sin textos fijos, ortografía australiana, un `h1` por página → `copy.test.ts`, `pages.test.tsx`. `pnpm lint`, `typecheck`, pruebas de la web (90) y `pnpm --filter @mt/web build` en verde; CI en el PR.
## Sin verificar
La e2e de navegador «crear en el panel, publicar y verla en la web» (criterio de fase) no existe: el panel es 1.2. Contraste y foco no probados en navegador. No se arrancó la web contra una API real, solo contra respuestas simuladas.
## Decisiones tomadas sin Oscar
Filtros solo los que ya admite la API (texto, distancia, tipo, mes, año, país): precio, tipo de entrada, estado y continente quedan para cuando la API los ofrezca (precios, 2.1). Lista de países sacada de las carreras publicadas (primeras 50). La guía solo muestra lo que hay en la API (resumen, mes, distancias, web); recorrido, clima y consejos necesitan un modelo de contenido nuevo. Sin botón de alerta (5.3): se dice que aún no hay paquetes. «Construir» solo se ofrece con el paquete en `open`. `/races/[slug]/build` deja de ser estática cerrada (`dynamicParams`) para aceptar carreras reales. Deshacer: revertir el PR.
