# 2.3 Constructor de paquete en la web
- **Estado:** hecha con pendientes
- **PR:** #23
- **Modelo:** Sonnet
- **Revisor:** no aplica (riesgo medio, plan propio en `docs/plans/2.3-package-builder.md`)
## Qué se hizo
`/races/[slug]/build?edition=&package=` carga el paquete de `/catalogue/races/:slug/editions/:year/packages/:pkg` y pinta el constructor (habitaciones y viajeros, tipo y distancia, noches extra, extras). Un componente de cliente pide el precio a `POST /api/pricing/quotes` y muestra total, depósito, saldo y desglose tal cual; la dirección guarda la configuración. Solo web: sin API, migración ni dependencias.
## Cómo se comprobó
- La web nunca calcula ni envía un importe → `src/lib/builder.test.ts` (la petición pasa `quoteRequestSchema` estricto y no tiene claves de dinero/fecha/regla), `builder-page.test.tsx` (un total que no cuadra con las líneas se muestra tal cual; primer render sin total) y `quote-loader.test.ts` (la petición solo lleva elecciones). `formatMoney` solo coloca la coma decimal sobre la cadena (tabla hasta 12 dígitos, JPY/NZD, signo).
- Solo se ve la respuesta más reciente → `quote-loader.test.ts` (respuesta vieja que llega tarde se descarta; 409/422/429/red/200 mal formado son errores, no totales).
- Disponibilidad en tres estados, sin cifras → `builder-page.test.tsx`. Sin afirmar «entrada garantizada» ni socio/acreditación salvo `guaranteedEntry` de la API → ídem y `pages.test.tsx`.
- Paquete inexistente, dirección mala o no `open` → `builder-page.test.tsx`. Etiquetas, fieldsets, `aria-live` → ídem. Copy por la capa de traducción, ortografía australiana → `copy.test.ts` (verde).
- Local: lint, tipos, 206 pruebas de la web y `pnpm --filter @mt/web build` en verde; CI en el PR.
## Sin verificar
Comportamiento en navegador (debounce, `replaceState`, foco, contraste, 320 px): no hay jsdom ni Testing Library y no se arrancó la web contra una API real; la e2e completa («buscar, configurar, solicitar») es del cierre de fase y necesita 2.4. La lógica de pedir/descartar está probada fuera de React.
## Decisiones tomadas sin Oscar
Sin JavaScript no hay precio (aviso `noscript`); alternativa: formulario GET con cotización en servidor. Hasta 4 habitaciones en la web (la API admite 20). Sin campo de código promocional ni reglas: 2.2 los define; se muestran `promo.status` y las líneas que devuelva la API (rótulo genérico «Discount»/«Surcharge»: la API no envía el nombre de la regla). Los extras obligatorios se listan como incluidos y no se envían (la API los añade). Deshacer: revertir el PR.
## Para la revisión de Oscar
Abrir `/races/<slug>/build?edition=<año>&package=<slug>` con un paquete `open` y tarifas publicadas, cambiar habitación, ocupación, noches y extras, y comparar el total con el panel (cotización de 2.1).
## Bloqueado por algo externo
Nada. Pagos, GST y divisas quedan fuera: solo se formatea el importe y la moneda que devuelve la API.
## Dependencias añadidas
Ninguna.
