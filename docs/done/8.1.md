## Qué se hizo

## Cómo se comprobó
- Publicar una guía no requiere desplegar → `apps/api/test/modules/content/content.test.ts` (`pages: publishing needs no deploy`, `race guides`); a mano: API y web reales, cambio en la base visible en la web a los ~60 s sin reiniciar (página, banner a los 60 s, redirección a los 30 s).
- Páginas legales siguen pendientes hasta que alguien con permiso las revise → mismo archivo, grupo `legal pages stay marked as pending…` (editar el texto no lo quita; solo la ruta `legal-review`, permiso propio, auditada); web: `apps/web/src/app/content-pages.test.tsx` (`legal pages stay marked…`, también con la API caída).
- Texto plano, nunca HTML; direcciones seguras (`javascript:`, `//`, `http:` rechazadas); redirecciones sin bucles, cadenas largas ni rutas reservadas; alt obligatorio o decorativa; CHECK de base de datos → `content.test.ts` (`redirects`, `image library`, `the database backs the rules up`) y `content-pages.test.tsx`.
- Permisos separados (leer, gestionar, publicar, redirecciones, revisión legal), versión optimista y auditoría → `content.test.ts` (`access`, `audit`).
- Web tolerante a API caída, sin textos fijos, un `h1` por página, sin afirmaciones de acreditación → `pages.test.tsx`, `copy.test.ts`, `content-pages.test.tsx`; panel: `components/admin/content/content.test.ts`, `lib/content.test.ts`.
- `pnpm lint`, tipos de API y web, 642 pruebas de API (todas verdes salvo `ops/backup.test.ts`, que necesita superusuario de PostgreSQL), 286 de web y `next build` en verde; CI en el PR.

## Decisiones tomadas sin Oscar
Imágenes por dirección (https o ruta del sitio), sin subida de archivos (la API no tiene recepción de ficheros); subirlas se añade después sin cambiar el modelo. Texto plano en vez de Markdown. Idioma como columna `locale` (por defecto en-AU), sin traducciones automáticas ni respaldo entre idiomas (8.2). Migración 0012 (0010 y 0011 reservadas). Sin interruptor de módulo: el contenido es núcleo. Una edición de algo publicado se ve a los ~60 s (sin borrador paralelo). Redirecciones: 301/302/307/308 exactas, lista en memoria 30 s. Deshacer: revertir el PR y una migración nueva que borre las tablas `content_*`.
